## 7.1. `load_csv($ruta, $delim)` — CSV y TSV

```zeta
$df = load_csv("tests/datos.csv")
print($df)
```

`load_csv` lee un archivo CSV, parsea el header, infiere tipos por columna, y devuelve un DataFrame. Soporta delimitadores configurables (coma, tabulación, punto y coma, etc.).

### Formato CSV esperado

```
mes,ventas,gastos
Ene,1000,500
Feb,1200,600
Mar,1500,700
```

- **Primera fila**: header con nombres de columnas.
- **Filas siguientes**: valores separados por el delimitador.
- **Líneas vacías**: se ignoran.
- **Tipos**: se infiere automáticamente por columna (número, booleano, o cadena).

### Delimitador configurable

```zeta
# CSV con coma (por defecto)
$df = load_csv("datos.csv")

# TSV con tabulación
$df = load_csv("datos.tsv", "\t")

# CSV con punto y coma (común en Europa)
$df = load_csv("datos.csv", ";")

# CSV con pipe
$df = load_csv("datos.csv", "|")
```

### Ejemplo con tipos mixtos

```
nombre,edad,activo
Ana,25,true
Luis,30,false
María,28,true
```

```zeta
$df = load_csv("personas.csv")
print($df:nombre)    # <"Ana", "Luis", "María">
print($df:edad)      # <25, 30, 28>
print($df:activo)    # <true, false, true>
print(type($df:nombre[0]))   # "str"
print(type($df:edad[0]))     # "num"
print(type($df:activo[0]))   # "bool"
```

### Nulls y valores faltantes

```
mes,valor,flag
Ene,100,1
Feb,,0
Mar,150,1
Abr,NA,1
```

```zeta
$df = load_csv("datos.csv")
print($df:valor)           # <100, null, 150, null>
print(is_null($df:valor))  # <false, true, false, true>
print(sum($df:valor))      # 250 (ignora nulls)
```

### Columnas faltantes por fila

Si una fila tiene menos columnas que el header, las faltantes se rellenan con `null`:

```
a,b,c
1,2,3
4,5
6
```

Resultado: `a` = `<1, 4, 6>`, `b` = `<2, 5, null>`, `c` = `<3, null, null>`.

## 7.2. `load_json($ruta)` — JSON a DataFrame

Lee un JSON con un array de objetos y lo convierte en un DataFrame.

### Formato esperado

```json
[
  {"nombre": "Ana", "edad": 25, "activo": true},
  {"nombre": "Luis", "edad": 30, "activo": false}
]
```

```zeta
$df = load_json("personas.json")
print($df:nombre)    # <"Ana", "Luis">
print($df:edad)      # <25, 30>
print($df:activo)    # <true, false>
```

Los tipos se infieren automáticamente: números, booleanos, cadenas, y `null`.

## 7.3. `load_xlsx($ruta)` — Excel XLSX

Lee un archivo Excel y devuelve un DataFrame. Soporta columnas de texto, números y booleanos.

```zeta
$df = load_xlsx("reporte.xlsx")
print("Filas:", len($df))
print("Columnas:", keys($df))
print($df:ventas)
```

## 7.4. Guardar datos

### `save_csv($ruta, $df, $delim)`

Guarda un DataFrame como CSV:

```zeta
$df = load_csv("ventas.csv")

# Guardar como CSV con coma (por defecto)
save_csv("ventas_backup.csv", $df)

# Guardar como TSV
save_csv("ventas.tsv", $df, "\t")

# Guardar como CSV europeo
save_csv("ventas_eu.csv", $df, ";")
```

### `save_xlsx($ruta, $df)`

Guarda un DataFrame como Excel:

```zeta
$df = load_csv("datos.csv")
save_xlsx("reporte.xlsx", $df)
```

### `guardar_grafo($ruta)` — Guardar escena

Guarda la escena de visualización actual como JSON:

```zeta
$scn = scene("Mi Reporte", "zeta")
add_metric($scn, "Total", sum($df:ventas))
guardar_grafo("mi_reporte.json")
```

## 7.5. `ZETA_PATH` para búsqueda de módulos

`ZETA_PATH` es una variable de entorno que extiende las rutas de búsqueda para módulos `.zl` y librerías nativas:

```bash
# En tu .bashrc
export ZETA_PATH="$HOME/.local/lib/zeta:/opt/zeta/lib"
```

Esto permite `include "mimodulo"` sin especificar la ruta completa, y `load_lib("libfoo.so", ...)` sin ruta absoluta.

## 7.6. Buenas prácticas

### Verificar antes de cargar

```bash
# Verificar tamaño del CSV
wc -l datos.csv

# Verificar que no esté vacío
test -s datos.csv && echo "OK" || echo "VACÍO"
```

### Validar después de cargar

```zeta
$datos = load_csv("datos.csv")

# Verificar columnas esperadas
if (!is_error($datos:ventas)) {
    print("Columna 'ventas' OK")
} else {
    print("ERROR: no se encontró 'ventas'")
    return
}

# Verificar no-vacío
if (len($datos) == 0) {
    print("Dataset vacío")
    return
}
```

### Manejar errores con `?`

```zeta
$df = load_csv("puede_no_existir.csv")?
print(len($df))
```

Si el archivo no existe, el error se propaga y aborta la ejecución del script.

## 7.7. Rendimiento

| Tamaño | Tiempo aprox. | Notas |
|--------|---------------|-------|
| 10 MB / 100K filas | ~170ms | Parser single-pass C++ |
| 100 MB / 1M filas | ~1.5s | Sin índices ni cache |
| > 1 GB | No recomendado | Usa DuckDB o pre-procesa |

El parser es **single-threaded** y hace una sola pasada sobre el archivo.
