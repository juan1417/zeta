Características

Diseñado para analistas de datos, ingenieros de sistemas y diseñadores de DSL.

{ }

Sintaxis híbrida

Familiaridad de Python con la robustez de Rust. Variables con $, colecciones con <>, y un sistema de tipos dinámico con 15 tipos de valor.

⚡

Motor C++20

Intérprete de alto rendimiento sin GC. Pipeline completo: Lexer → Parser → AST → Interpreter.

▦

DataFrames nativos

Carga CSV con load_csv, accede a columnas con $datos:ventas, y transforma datos sin dependencias externas.

✓

Errores y null como datos

Propagación de errores con ?, is_error, is_null. Null se comporta como NaN, no como excepción.

☍

C ABI — load_lib

Carga .so / .dll con un solo load_lib(...). Marshalling automático de vectores Zeta a punteros C.

◆

Tres renderers

zeta_dashboard (OpenGL + ImGui), zeta_term (ANSI 24-bit), y un servidor HTTP REST con endpoints para datos, métricas y gráficos.

Instalar en tu sistema

Elige tu sistema operativo para ver los pasos de instalación.

Linux (Debian / Ubuntu)

tar xzf zeta-linux-x64.tar.gz && sudo cp zeta zeta_server zeta_dashboard zeta_term /usr/local/bin/

macOS

tar xzf zeta-macos-arm64.tar.gz && sudo cp zeta zeta_server zeta_dashboard zeta_term /usr/local/bin/

Windows

Expand-Archive zeta-windows-x64.zip -DestinationPath C:\zeta; $env:PATH += ";C:\zeta"

Binarios incluidos

zeta

~640 KB

Intérprete CLI. Ejecuta scripts .zl.

zeta script.zl

zeta_server

~1.2 MB

Servidor HTTP REST con Crow.

zeta_server --port 8080

zeta_dashboard

~3.6 MB

Renderer OpenGL + ImGui + ImPlot.

zeta_dashboard --host localhost

zeta_term

~234 KB

Renderer ANSI 24-bit. Sin OpenGL, SSH-friendly.

zeta_term --host localhost --width 120
